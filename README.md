# ❄️ Winter Arc 2026: Личный Интерактивный Дашборд Эффективности

Добро пожаловать в мой репозиторий челленджа **Winter Arc**! Этот проект создан для визуализации ежедневного прогресса, удержания фокуса и развития жесткой дисциплины в период с **5 октября по 31 декабря 2026 года**.

Дашборд разработан на **Python** с использованием библиотеки **Streamlit** и кастомизирован под стильную темную тему.

## 🎯 Глобальные Цели и Фокус
*   **Основной вектор**: Стать крутым менеджером по продажам / РОПом 🚀
*   **Правило дня**: «Каждый день я становлюсь на 30 минут компетентнее» (инвестиции в развитие профессиональных навыков).

## ⚡ Особенности функционала
*   **Игровая механика**: Динамическая шкала «Дисциплина» (старт со 100 баллов, штраф -5 баллов за каждый пропуск). Задача — держать баланс выше 80.
*   **Качественные итоги**: Текстовый архив главных побед недели.
*   **Локальное хранение**: Все данные сохраняются локально на ПК в формате `JSON` и не сбрасываются при перезапуске (файл данных скрыт через `.gitignore`).
*   **Аналитика**: Линейный график динамики изменения уровня дисциплины по дням.

## 🛠 Инструкция по локальному запуску

Для запуска приложения вам понадобятся **Python** и установленные библиотеки `streamlit` и `pandas`.

1. Клонируйте репозиторий или скачайте код к себе на компьютер.
2. Откройте терминал в папке проекта и установите зависимости:
   ```bash
   pip install streamlit pandas
   ```
3. Запустите дашборд командой:
   ```bash
   streamlit run winter_arc_tracker.py
   ```
4. Приложение автоматически откроется в вашем браузере по адресу `http://localhost:8501`.
